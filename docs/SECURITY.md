# Security boundaries

Only synthetic cases are supported. Presidio pattern recognizers and a Verhoeff validator mask detectable identifiers before graph invocation, model calls, cache writes, traces, checkpoints, and ledger writes. The token map remains in process memory. Retrieved chunks are screened for obvious instruction injection and are presented to the generator as untrusted evidence. Output citations must belong to the retrieved set; invalid citations trigger one repair and then escalation. The app refuses legal-advice and inheritance-adjudication requests. Node logs hold only hashed case IDs and timings.

Current limits: names are not reliably detected; an adaptive indirect injection may pass regex screening; citation membership does not prove a claim is supported by the cited passage; replay sources are synthetic. Do not deploy for real customers without a reviewed corpus, stronger PII coverage, passage-level support checks, red-team results, and a privacy review.
